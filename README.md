# The Printer Apology

This project delivers a heartfelt, albeit slightly passive-aggressive, office printer apology to everyone who has ever jammed it, fed it cheap paper, and sworn at it in frustration. Selected from six rigorous candidates scored against the judge brief, the ultimate peace offering was chosen: "I am sorry I swallowed the quarterly report whole, but your recycled office stock lacks the crunch of real wood pulp."

## Run it

```sh
python3 main.py
```
